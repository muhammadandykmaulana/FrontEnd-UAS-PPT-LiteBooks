Masalah: Dokumentasi Tercecer

Materi kuliah, snippet kode, dan tutorial teknis sering tersebar di Notepad, WhatsApp, atau Google Docs. Format teks biasa tidak mendukung Syntax Highlighting untuk kode program.

Solusi LiteBooks:
Aplikasi perpustakaan digital terpusat yang mendukung format Markdown, database persisten, dan akses yang aman.

Refleksi & Tantangan Teknis

Pembelajaran utama selama proses pengembangan

Markdown Rendering
Teks video & tabel awalnya tidak muncul, hanya teks biasa.
Solusi: Mengimplementasikan plugin remark-gfm dan rehype-raw untuk parsing HTML kompleks.
Env Variables
Koneksi DB gagal di lokal karena ENV tersimpan di GitHub Secrets.
Solusi: Konfigurasi manual .env.local dan penanganan error handling yang baik.
Empty State
Tampilan aplikasi terlihat "rusak" saat database kosong (awal clone).
Fitur Unik: Membuat logika Auto-Seeding yang otomatis mengisi DB jika data 0.
